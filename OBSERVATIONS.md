# Observations

A drain for things noticed while reading a source system that are **not** skill
content — a security concern, a suspected bug, a design smell in the tool being
documented. `AGENTS.md` sends them here so that an agent authoring a skill has
somewhere to put one and can then stop thinking about it.

One line each: what was seen, and where. No investigation, no severity, no fix.
Nothing in this repository reads this file automatically; a human does, when
they choose to.

```
- <system or command> — <one line>
```
